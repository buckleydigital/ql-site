CRM Integration Setup

To send your leads straight into your CRM in real time, we push each new enquiry to your system via an HTTP POST. To set this up, we need a few details from you.

1
What we need
  1. 1

    Endpoint URL

    The URL we should POST your leads to.

  2. 2

    Format

    How the data should be sent (JSON, form-data, etc.).

  3. 3

    Authentication

    Any API key, token, or header your endpoint requires.

  4. 4

    Field mapping

    The exact field names your CRM expects, so we can match our form fields to yours. Our form captures:

    name email phone postcode purchase timeline average quarterly bill

If your CRM has API documentation, just send us the relevant page and we'll take it from there.

2
Sending your API key or token securely

Never send API keys or tokens over plain email

Please send any sensitive credentials using onetimesecret.com. Paste your key there, generate a one-time link, and send us that link. It can only be opened once and then it's gone, which keeps your credentials safe.
