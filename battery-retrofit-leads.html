Lead Types

Lead types built for
every battery retrofit scenario.

Not every battery retrofit is the same. Some homeowners have compatible hybrid inverters and just need a DC-coupled battery. Others need an AC-coupled solution or a full hybrid inverter upgrade. These lead types are configured at setup and mapped directly to your quoting workflow.

AC-coupled retrofit

Homeowners with an existing string inverter who want to add a standalone battery with its own inverter. No changes to existing solar wiring. Fastest install path for most retrofit jobs - ideal for Fronius, SMA, or Sungrow string inverter systems.

DC-coupled / hybrid upgrade

Homeowners ready to replace their existing inverter with a hybrid unit and add DC-coupled battery storage. Higher-value jobs with better long-term efficiency. Common when the existing inverter is aging or undersized for the system.
